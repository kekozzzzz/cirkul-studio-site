## Хостинг переехал: Netlify → Beget, 26.07.2026 (см. память [[feedback_ru_hosting_vpn_pattern]])
Причина: Netlify (и Vercel/Cloudflare Pages) периодически блокируются/тормозят в РФ без VPN —
задокументированная проблема. Решение (обсудили и согласовали с Артёмом):
- **Netlify остаётся** — только как движок CMS (Decap CMS через Identity/Git Gateway), сюда
  же продолжают приходить коммиты и автосборка. Публично никому не показываем этот адрес
- **Beget FreeHosting** — бесплатный тариф, публичный домен `циркуль-сургут.рф` теперь смотрит
  сюда. Аккаунт и FTP-доступы — в `ДОСТУПЫ.md` (локальный, в git не коммитится)
- **GitHub Action** (`.github/workflows/deploy-beget.yml`) — при каждом пуше в `main` (включая
  коммиты из CMS через Git Gateway) сам собирает сайт и заливает на Beget по FTPS через `lftp`
  (обычный Node-экшен `FTP-Deploy-Action` не смог даже с FTPS — теперь через `lftp`,
  `--parallel=4`, с реальной проверкой после деплоя через curl вместо доверия exit-коду lftp,
  который иногда падает на безобидном TLS-предупреждении при закрытии соединения)
- **Важный нюанс:** Beget отдаёт 403 на запросы без «браузерного» User-Agent (антибот-защита
  бесплатного тарифа) — это не баг, обычные посетители видят сайт нормально
- DNS домена переведён с Netlify DNS на `ns1/ns2.beget.com`, `ns1/ns2.beget.pro`. Зона `.рф`
  публикуется пакетами (не мгновенно, в отличие от смены на Netlify) — подключение SSL
  (Let's Encrypt через панель Beget) ждём, пока разойдётся глобально
- **Компромисс, согласован с Артёмом и Валерием:** обычные посетители — без VPN всегда.
  Валерию для входа именно в CMS (не для просмотра сайта) периодически нужен VPN, т.к. админка
  живёт на Netlify. Приемлемо — правки делает один человек нечасто

**Доступ к контенту для Валерия:** решили дать полноценный — не только фото по разделам, но и
телефон, политику конфиденциальности, согласие на обработку данных теперь тоже редактируются
через CMS (см. ниже). Оферту оставили как отдельный `.njk` с готовым текстом — сложнее
структура (аккордеон), не трогали.

**Про «защиту от неоплаты» (обсуждали с Артёмом, ничего технического не строили):** специальный
механизм «удалить всё одной кнопкой» не нужен — Артём и так полностью контролирует
GitHub/Netlify/Beget аккаунты (все три — на его данных), может в любой момент остановить показ
сайта штатными средствами панелей. Домен — единственное, что по договорённости оформлено на
клиента, но без хостинга сайт всё равно не откроется. Явно решили не заводить отдельную
«кнопку сноса» — это то же самое действие руками, только с риском случайной ошибки.

## Хостинг переехал ещё раз: Beget FreeHosting (Артём) → Beget платный (Валерий), 26–28.07.2026
**Выяснилось: на бесплатном тарифе Beget самостоятельный заказ SSL вообще недоступен** —

кнопка «Управление SSL сертификатами» так и не появилась даже после полного распространения
DNS + суток ожидания + отсутствия ответа от бесплатной поддержки). Без HTTPS работать
не вариант (Google, доверие) — обсудили с Артёмом альтернативы (Yandex Cloud, другой хостинг),
но **Валерий сам согласился платить за хостинг** — это и есть чистое решение, раз именно
его бизнесу нужен работающий сайт.

**Итог:**
- Хостинг переехал на **отдельный аккаунт Beget, зарегистрированный и оплачиваемый Валерием**
  (не Артёмом) — правильно, раз это его текущий расход, не должен молча висеть на
  разработчике (см. [[feedback_ru_hosting_vpn_pattern]], туда же добавлена соответствующая
  поправка)
- Тариф — платный «Blog» (~420₽/мес) — там SSL заказывается за пару минут без вопросов
- **Важный нюанс архитектуры платных тарифов Beget:** каждый домен на аккаунте — это
  отдельный сайт со своей папкой (не общий `public_html`, как было на бесплатном одном
  сайте). Путь для FTP: `/<транслитерация-домена>/public_html/` — из-за этого один раз

(держат уже опубликованный сайт живым) — отдельный пул, **не тратится на новые сборки** и
не тратился ими. А вот пул именно под сборки закончился.

**Решение:** поставили Netlify на **«Stopped builds»** (Project configuration → Build &
deploy → Continuous deployment → Build settings) — сборки больше не расходуют кредиты
впустую, ни от моих пушей, ни от правок Валерия через CMS. **Это не блокирует ничего важное:**
- Публичный сайт полностью идёт через GitHub Action → Beget, от Netlify не зависит вообще
- Identity + Git Gateway (вход в CMS, коммит правок) работают независимо от статуса сборок —
  проверено на практике, правки Валерия исправно коммитятся, даже когда сборки стоят
- Из-за этого часть кода (например, русская локализация админки `locale: "ru"`, добавленная
  25.07) физически лежит в GitHub, но никогда не собиралась Netlify — на живой админке её
  не видно. Не критично, можно один раз включить сборки обратно после 23 августа (сброс
  кредитов), собрать актуальную версию и снова остановить

**Также обнаружили и починили:** на самом сайте (не только в `/admin/`) не хватало скрипта
Netlify Identity widget — из-за этого ссылка-приглашение по email вела на главную страницу
без окна для пароля. Добавили в `base.njk`. Рабочий обход, если сборки Netlify снова встанут
в будущем — раздавать ссылки на вход сразу с `/admin/` (там виджет был всегда, с первого дня).
